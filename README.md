# ♻️ IntelliBin — AI Waste Segregation System

IntelliBin is an AI-powered waste classification web application that detects and categorizes waste using Deep Learning and Computer Vision.

The platform helps users identify recyclable waste materials and promotes smart waste disposal for a cleaner and greener future.

---

# 🚀 Features

- 🔬 AI Waste Detection using TensorFlow/Keras
- 📷 Upload Image Waste Analysis
- 🎥 Live Webcam Waste Detection
- 📊 Real-Time Analytics Dashboard
- ♻️ CO₂ Tracking System
- 📜 Detection History
- ☁️ MongoDB Atlas Database Integration
- 🎨 Modern Responsive UI
- ⚡ Full Stack Architecture (React + Flask)

---

# 🧠 AI Model

The AI model is trained to classify the following waste categories:

- Cardboard
- Glass
- Metal
- Paper
- Plastic

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Vishaljadoun63/IntelliBin-AI-Waste-Segregation.git
```

---

# 💻 Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```

---

# ⚙️ Backend Setup

```bash
cd backend
pip install -r requirements.txt
python app.py
```

Backend runs on:

```bash
http://127.0.0.1:5000
```

---

# ☁️ MongoDB Setup

- Create MongoDB Atlas Cluster
- Add your MongoDB connection string inside:

```bash
backend/.env
```

Example:

```env
MONGO_URI=your_mongodb_connection_string
```
